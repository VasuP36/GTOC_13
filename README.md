# Humanity’s First Robotic Exploration of a Hypothetical Exoplanetary System
Team **KeplerianHitchhikers**' attempt at the problem statement of the 13th Global Trajectory Optimization Competition (GTOC-13)

## Using pykep
The [pykep](https://esa.github.io/pykep/) library needs to be setup via miniconda.

How to setup:
- Install miniconda for Windows/Linux as described [here](https://www.anaconda.com/docs/getting-started/miniconda/install)
- Switch to the `base` environment or simply use the Anaconda Prompt/Anaconda Powershell Prompt (On Windows), and then follow the instructions described [here](https://esa.github.io/pykep/installation.html#conda)
